# Fixture licenses

All programs in this directory were authored for SolidPDF and are distributed under the repository license.

`Programs/permissive-raster-box.ps` is additionally dedicated to the public domain under CC0 1.0 so it can serve as a license-attributed interoperability fixture.

`Programs/raster-adjacent-triangles.ps`, `Programs/raster-transformed-curves.ps`, and
`Programs/raster-dense-bezier-silhouette.ps` are independent project-authored reductions. They contain no source from
the external Ghostscript examples whose paths and digests appear in the observational discovery baseline.
